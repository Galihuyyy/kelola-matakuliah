### 🚀 Getting Started

Ikuti langkah-langkah berikut untuk mendapatkan dan menjalankan project ini.

1. Clone Repository

   Clone merupakan proses menyalin repository dari GitHub ke komputer lokal.

   Buka terminal, kemudian jalankan:
    
    ```bash
    git clone https://github.com/Galihuyyy/kelola-matakuliah.git
    ```
  
    Masuk ke direktori project:
    
    ```bash
    cd kelola-matakuliah
    ```

3. Membuka Project
   Jika menggunakan Visual Studio Code, jalankan:
   
    ```bash
    code .
    ```
    
    Perintah tersebut akan membuka folder project menggunakan VS Code.
